## 🚀 1. 快速上手 (Quick Start)

```bash
# 1. 列出全曲 16 個 SET 段落、[STYLE] 標籤與原詞總覽
python3 gumen_cli.py list

# 2. 檢視指定段落（例如 SET_04 Chorus 1）的原詞與全部 Prompts（可選 dual / heroine / abstract）
python3 gumen_cli.py set 4 --mode heroine

# 3. 切換為「無人物純抽象器物模式 (λ_H=0)」檢索單一關鍵幀
python3 gumen_cli.py get SET_04_K07_1080P --mode abstract

# 4. 依原詞關鍵字搜尋對應鏡號與 Prompt
python3 gumen_cli.py search "裂月"

# 5. 一鍵匯出全曲 144 張關鍵幀的純文字 Prompts
python3 gumen_cli.py export --type keyframes --mode heroine --out keyframes_heroine_144.txt
python3 gumen_cli.py export --type keyframes --mode abstract --out keyframes_abstract_144.txt
```
